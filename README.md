# اپلیکیشن فوروارد پیامک بانک

اپ اندرویدی ساده که پیامک‌های بانک (مثلاً بانک ملی) را بر اساس **نام/شماره‌ی فرستنده** تشخیص می‌دهد و متن آن‌ها را به یک شماره‌ی دلخواه که در تنظیمات وارد می‌کنید، **به‌صورت پیامک (SMS)** فوروارد می‌کند.

---

## ۱) گرفتن APK آماده (بدون نصب اندروید استودیو)

ساده‌ترین راه، استفاده از GitHub Actions است که فایلش داخل پروژه قرار دارد:

1. یک ریپازیتوری جدید (می‌تواند Private باشد) در GitHub بساز.
2. تمام محتویات این پوشه را در آن ریپو بگذار (push کن).
3. در ریپو برو به تب **Actions** → اگر پرسید، اجرای workflowها را تأیید کن.
4. workflow با نام **Build APK** خودکار اجرا می‌شود (یا از دکمه‌ی **Run workflow** دستی اجرایش کن).
5. بعد از چند دقیقه، وارد آن اجرای موفق شو و از بخش **Artifacts** فایل `app-debug-apk` را دانلود کن. داخلش `app-debug.apk` هست.
6. این APK را روی گوشی نصب کن (باید «نصب از منابع ناشناس» را برای مرورگر/فایل‌منیجر فعال کنی).

> این APK از نوع **debug** است؛ برای نصب شخصی کاملاً کافی است و نیازی به امضای release ندارد.

## روش جایگزین: بیلد در اندروید استودیو

پوشه را در Android Studio با **Open** باز کن، اجازه بده Gradle سینک شود، بعد:
`Build → Build Bundle(s) / APK(s) → Build APK(s)`
یا در ترمینال داخل پوشه:

```bash
./gradlew assembleDebug
```

خروجی در `app/build/outputs/apk/debug/app-debug.apk` ساخته می‌شود.

---

## ۲) تنظیم و استفاده

1. اپ را باز کن و دسترسی **پیامک (دریافت و ارسال)** را بده.
2. **شماره‌ی مقصد** را وارد کن (پیام‌ها به این شماره می‌روند).
3. در کادر **فرستنده‌های بانکی**، دقیقاً همان چیزی را بنویس که روی گوشی‌ات به‌عنوان فرستنده‌ی بانک نشان داده می‌شود.
   - این می‌تواند یک نام مثل `BANKMELLI` باشد یا یک شماره/کد کوتاه.
   - چند فرستنده را با کاما یا خط جدید از هم جدا کن.
   - تطبیق به‌صورت «شامل بودن» و بدون حساسیت به بزرگ/کوچک بودن حروف انجام می‌شود.
4. کلید **فوروارد فعال باشد** را روشن کن و **ذخیره** را بزن.

از این به بعد هر پیامکی که فرستنده‌اش با لیست بخواند، به شماره‌ی مقصد فوروارد می‌شود.

---

## ۳) نکات مهم واقعی

- **فرستنده‌ی واقعی بانک ملی را خودت وارد کن.** مقادیر پیش‌فرض داخل اپ فقط نمونه‌اند و ممکن است با چیزی که روی گوشی تو نمایش داده می‌شود فرق داشته باشند. یک پیامک قبلی بانک را باز کن و عین نام/شماره‌ی فرستنده را کپی کن.
- **اپ را حداقل یک‌بار باز کن.** تا وقتی اپ یک‌بار اجرا نشده باشد، اندروید پیامک‌ها را به آن نمی‌رساند. اگر اپ را Force Stop کنی هم تا باز شدن دوباره کار نمی‌کند.
- **بهینه‌سازی باتری / Autostart.** روی برخی گوشی‌ها (شیائومی/MIUI، هواوی، سامسونگ و...) باید اجازه‌ی **اجرای خودکار (Autostart)** را بدهی و اپ را از **بهینه‌سازی باتری** خارج کنی، وگرنه وقتی اپ بسته است ممکن است پیامک‌ها نرسند.
- **هزینه‌ی پیامک.** هر فوروارد یک پیامک معمولی است و طبق تعرفه‌ی اپراتورت هزینه دارد. پیام‌های فارسی بلند چند تکه می‌شوند.
- **دو سیم‌کارته.** ارسال با سیم‌کارت پیش‌فرض پیامک گوشی انجام می‌شود.
- این اپ روی Google Play قابل انتشار نیست (به‌خاطر محدودیت دسترسی پیامک)، ولی برای نصب شخصی روی گوشی خودت مشکلی نیست.
